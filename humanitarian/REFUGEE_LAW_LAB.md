# Refugee Law Lab research integration

This is a **read-only resource registry**, not a live API client or installed copy of the datasets.

Run: `python -m humanitarian.refugee_law_lab --query Afghanistan`.

Sources: https://refugeelab.ca/projects/ ; https://github.com/Refugee-Law-Lab ; https://refugeelab.ca/bulk-data/rllr/ ; https://api.a2aj.ca/docs

## Restrictions
- The RPD and RLLR datasets state CC BY-NC 4.0. Do not mirror, redistribute, embed or commercially exploit these datasets without confirming licensing permission.
- Do not treat historical Canadian decisions as current humanitarian programme openings, visa eligibility or binding legal advice.
- No private applicant data, outreach, scraping or automatic submission.
- A2AJ is a related successor legal-data project, not an official immigration authority. Its API is documented publicly, but access, licensing and uptime require separate verification.
- Verify each case with official Canadian sources and check current immigration rules before relying on findings.
